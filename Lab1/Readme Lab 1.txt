Lab 1 Programs

The first laboratory session covers basic Python programming concepts:

 1. Variable Practice

Demonstrates:

* Variables
* Different Python data types
* `type()` function
* Boolean values

 2. Greeting Program

Demonstrates:

* User input
* Type conversion
* F-strings
* String formatting

 3. Arithmetic Operations

Performs:

* Addition
* Subtraction
* Multiplication
* Division
* Remainder

 4. Celsius to Fahrenheit

Converts a temperature from Celsius to Fahrenheit using:

F = (C × 9/5) + 32

 5. String Manipulation

Demonstrates:

* Uppercase conversion
* Lowercase conversion
* String reversal
* String length

 6. Escape Sequence Practice

Demonstrates the use of:

 \t — Tab
 \n — New line

to create a simple receipt/table-like output.

 7. Calculator

A menu-driven calculator supporting:

* Addition
* Subtraction
* Multiplication
* Division
* Exit option
